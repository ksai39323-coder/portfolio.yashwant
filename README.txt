PERSONAL PORTFOLIO WEBSITE

Files:
- index.html : Website structure and content
- style.css  : Responsive styling and layout
- script.js  : Contact form validation and small interactions

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it with VS Code and use Live Server.
4. Internet connection is required for Bootstrap and Google Fonts CDNs.

CUSTOMIZE BEFORE SUBMISSION:
- Your name is already set to "Gorantla Yashwanth" and initials "GY"., email, city, college, branch and education dates.
- Replace the sample project descriptions with your own projects.
- Update skill labels and progress percentages.
- Replace the sample email address in script.js and index.html.
- Add your own profile photo by replacing the profile-placeholder block in index.html with:
  <img src="images/profile.jpg" alt="Your Name" class="profile-photo">
  Then add suitable styling for .profile-photo in style.css.
- The contact form validates the fields and opens the visitor's email application.
  It does not store or send messages to a server.

Built with HTML, CSS, JavaScript and Bootstrap 5.
